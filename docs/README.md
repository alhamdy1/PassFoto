# Documentation

This folder contains documentation assets for PassFoto.

## Files

- `screenshot.png` - Application screenshot (to be added)
- `INSTALLATION.md` - Detailed installation guide
- `USAGE.md` - Detailed usage instructions

## Adding Screenshots

To add a screenshot:
1. Run the application: `python main.py`
2. Take a screenshot with an image loaded
3. Save as `screenshot.png` in this folder
